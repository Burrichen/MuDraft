MuDraft 1.0.0: a first release of the local-first music backlog, Next Up picker, and collection.

**Windows x64: unsigned personal release.** The installer has no Authenticode signature, so Windows SmartScreen or antivirus software may warn about it. Check the file against `SHA256SUMS.txt`.

- `MuDraft_1.0.0_windows_x64_setup.exe` installs for the current user, with no administrator rights needed.
  - It includes Microsoft's offline WebView2 installer, so a first install works without a network connection. This adds about 127 MB.
- Your profile is stored in `%LOCALAPPDATA%\app.mudraft.desktop`.
  - Upgrading keeps it.
  - Uninstalling keeps it unless you tick "Delete the application data".
- This release has a new neutral charcoal look with blue accents. Listen ASAP now defaults to mustard yellow. If you chose your own colour for it, that colour is kept.

There is no macOS build in this release. See `docs/WINDOWS.md` for details and `docs/RELEASE_BLOCKERS.md` for known limitations.
