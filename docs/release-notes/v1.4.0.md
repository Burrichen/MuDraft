MuDraft 1.4.0: several Next Up picks at once, and updates from inside the app.

- **Next Up** holds up to five albums. Each has its own picking method, and a roll never picks an album that's already in your Next Up.
- **Updates.** MuDraft checks for updates when it starts and offers to install them, with a short note on what's new. You can also check from Settings → Version.
- **Tag filters:** click a tag once for albums with it, again for albums without it (shown in red), and once more to clear it.
- **Listen ASAP** can now be deleted in Settings → Tags (new libraries still start with it). Without it, Weighted Random is unavailable.
- Album pages no longer have an About section.
- **Fixed:** on Mac, ticking a tag in the tag list didn't apply it.
- **Stats:** Top rated can rank by **Albums** or by **Tracks** (your individual track ratings). The "Albums listened to" and "Tagged Listen ASAP" cards are gone.
- **Artists:** discographies now sync between computers, so your progress matches everywhere. Singles and live recordings in your library no longer count toward an artist's progress.
- **Upgrading** keeps your library. Computers that sync together should all move to 1.4.0, because older versions can't read its sync data. Install 1.4.0 by hand once; later versions can update themselves.
