MuDraft 1.2.0: the first release for **both Windows and macOS**, and optional **GitHub Sync** between your computers.

- **macOS app.** A disk image (`.dmg`) with one MuDraft.app that runs natively on Apple Silicon and Intel Macs (macOS 12 or later). Drag it to Applications. See `docs/MACOS.md` for the one-time approval macOS asks for.
- **GitHub Sync (optional).** Keep your library the same on several computers through a private GitHub repository you own. It's set up in Settings → GitHub Sync, and syncs only when you click Sync Now.
  - Each computer uses its own fine-grained token, stored in Keychain (macOS) or Credential Manager (Windows).
  - The first sync previews both libraries and asks whether to upload, download, or merge.
  - Changes made on different computers are combined. If the same thing was changed on both, MuDraft shows both versions and lets you choose.
  - Your library is backed up before any synced changes are applied.
  - A private repository is not end-to-end encrypted.
  - Setup steps: `docs/SYNC.md`.
- **Upgrading** keeps your profile. The database moves to a new version automatically on first launch, after a backup in the data folder's `backups`. Profile export and restore (Settings → Profile) still work, and remain the way to move or recover a whole library.
- **Windows** is unchanged otherwise: the same per-user installer, which works offline.
