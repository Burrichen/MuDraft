MuDraft 1.5.0: Lists, and an Android app.

- **Lists** (new sidebar page). Keep track of curated album lists, each with a progress bar. Open a list to see every album and whether you've listened to it.
  - An album counts as listened when it's in your Collection. Albums only on your Listen List are shown, but don't count toward progress.
  - **Import from a web page.** Paste a Pitchfork ranked-list address, such as "The 100 Best Indie Rock Albums of All Time". MuDraft reads the page, shows what it found, and saves nothing until you confirm. You can also add albums by hand.
  - **Add unlistened to Listen List** adds every album you don't have a listen for, one by one or all at once. Albums already in your library are added straight away. Albums that aren't are added only after you pick the right MusicBrainz match (nothing is added automatically), so nothing is duplicated.
  - Lists are included in profile export and GitHub Sync. Deleting a list never touches your albums, Collection, or Listen List.
- **Editions.** You can now delete an extra edition on the album page. The last edition, and any edition with listens, ratings, liked tracks, or a review, can't be deleted. Adding an album no longer asks you to choose an edition when only one exists.
- **Upgrading** keeps your library. The database moves to a new version automatically on first launch, after a backup. Computers that sync together should all move to this version, because older versions can't read its sync data.
- **Android.** An APK is attached to this release (Android 7+). It has no Stats page; Liked takes its place in the menu. See docs/ANDROID.md. Install it over a previous MuDraft APK only if that one was signed with the same key; the first 1.5.0 APK uses a new key, so uninstall the 1.4.0 APK first (export your profile or sync beforehand, because uninstalling clears its data).
